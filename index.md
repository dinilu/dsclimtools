# dsclimtools

The goal of dsclimtools is to interact with the dsclim dataset. To do
so, this package provide functions that allow to read the data into R
objects of the `stars` class (from the `stars` package). It also provide
a few functions to modify and manipulate these objects (e.g. modify
dates, change units, etcetera).

## Installation

You can install the development version of dsclimtools like so:

``` r

library(devtools)
install_github("dinilu/dsclimtools")
```

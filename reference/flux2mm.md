# Flux 2 millimetters

Transform stars objects from precipitation in flux to precipitation in
millimeters

## Usage

``` r
flux2mm(data)
```

## Arguments

- data:

  A stars object with precipitation in flux

## Value

A stars object with precipitation in millimeters

## Examples

``` r
if (FALSE) { # \dontrun{
data <- read_trace("data/TraCE21ka/", "PRECC")
flux2mm(data)
} # }
```
